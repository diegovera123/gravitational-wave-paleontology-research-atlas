
# Mathematics

Mathematical foundations for gravitational-wave astrophysics and independent research.

## Units

### 1. Calculus
- Single-variable calculus
- Multivariable calculus
- Vector calculus

### 2. Linear Algebra
- Vectors and matrices
- Eigenvalues and eigenvectors
- Matrix decompositions

### 3. Differential Equations
- Ordinary differential equations
- Coupled differential equations
- Numerical solutions

## Learning Objectives

By completing the mathematics curriculum, learners should be able to:

1. Apply calculus to describe physical systems.
2. Use linear algebra to represent and analyze multidimensional problems.
3. Derive and solve differential equations governing physical systems.
4. Apply mathematical methods to gravitational-wave astrophysics.
